# LEARN HOW TO USE GITHUB

一个用于学习 GitHub 基本操作的练习仓库。

## 这是什么

这个仓库用来熟悉 Git 和 GitHub 的日常工作流：

- `git init` / `git add` / `git commit` —— 本地版本管理
- `git remote add` / `git push` / `git pull` —— 与远程仓库同步
- 分支、合并与 Pull Request —— 协作开发
- Issue、Actions —— 项目协作与自动化

## 快速开始

```bash
git clone https://github.com/OliviaBrown-sec/LEARN-HOW-TO-USE-GITHUB.git
cd LEARN-HOW-TO-USE-GITHUB
```

## 常用命令

| 目的 | 命令 |
| --- | --- |
| 查看状态 | `git status` |
| 查看提交历史 | `git log --oneline --graph` |
| 暂存全部改动 | `git add -A` |
| 提交 | `git commit -m "说明"` |
| 推送 | `git push` |
| 拉取 | `git pull` |
